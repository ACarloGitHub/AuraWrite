Local Embeddings

AuraWrite helps you keep track of your projects and documents using several memory systems. One of them is the "semantic" memory: it stores a numerical fingerprint (embedding) of your text so the AI can later find passages by meaning, not only by exact word match. To use it you need to download nomic-embed-text-v2-moe, a small open-source embedding model.

Keep in mind: nomic only creates the fingerprint and stores it. It cannot answer questions on its own. To actually query the vector database that nomic builds and get useful answers, you will also need a chat-capable AI model (see the AI Provider tab).

nomic needs a small runtime called llama.cpp (CPU only, for embeddings) to load the model. Both are downloaded the first time you choose to, and stored in your user data folder. You can remove them at any time from this tab.

AuraWrite connects to the internet only for AI provider APIs (OpenAI, Anthropic, DeepSeek, OpenRouter, MiniMax), model downloads from Hugging Face, and update checks from api.github.com. Local AI (Ollama, LM Studio, llama.cpp) connects to localhost only. No telemetry or analytics are sent.
All projects, documents, and settings are stored locally on your machine. The database is a SQLite file in the app data directory. Downloaded AI models are stored in the models directory (configurable in Local Models). Nothing is uploaded to any server unless you explicitly use a cloud AI provider.
When you send a message in the AI panel, AuraWrite includes the current document content and your selected text. Images and documents you attach are sent to the AI provider you have chosen. No content is stored on AuraWrite servers.

Welcome to AuraWrite

AuraWrite keeps track of your projects and documents using several memory systems. One of them is the semantic one: it stores a numerical fingerprint of your text so the AI can later retrieve passages by meaning, not only by exact word match.

To use it, you need to download nomic, a small open-source embedding model. Please note that nomic only builds the vector database: to actually query it and get useful answers, you will also need a chat-capable AI model, configured in the AI Provider tab.

nomic needs a small runtime called llama.cpp (CPU only, for embeddings) to load and run. Would you like to download both now? They will be stored in your user data folder and you can remove or update them at any time from Preferences → Embeddings. Downloads continue in the background even if you close this dialog.

llama.cpp is released under the MIT license. nomic-embed-text-v2-moe is released under the Apache 2.0 license. Both are open source and free for commercial use.
