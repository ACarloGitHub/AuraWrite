Local Embeddings

AuraWrite helps you keep track of your projects and documents using several memory systems. One of them is the "semantic" memory: it stores a numerical fingerprint (embedding) of your text so the AI can later find passages by meaning, not only by exact word match. To use it you need to download nomic-embed-text-v2-moe, a small open-source embedding model.

Keep in mind: nomic only creates the fingerprint and stores it. It cannot answer questions on its own. To actually query the vector database that nomic builds and get useful answers, you will also need a chat-capable AI model (see the AI Provider tab).

nomic needs a small runtime called llama.cpp to load the model. Both are downloaded the first time you choose to, and stored in your user data folder. You can remove them at any time from this tab.

Welcome to AuraWrite

AuraWrite keeps track of your projects and documents using several memory systems. One of them is the semantic one: it stores a numerical fingerprint of your text so the AI can later retrieve passages by meaning, not only by exact word match.

To use it, you need to download nomic, a small open-source embedding model. Please note that nomic only builds the vector database: to actually query it and get useful answers, you will also need a chat-capable AI model, configured in the AI Provider tab.

nomic needs a small runtime called llama.cpp to load and run. Would you like to download both now? They will be stored in your user data folder and you can remove or update them at any time from Preferences → Embeddings.

llama.cpp is released under the MIT license. nomic-embed-text-v2-moe is released under the Apache 2.0 license. Both are open source and free for commercial use.
